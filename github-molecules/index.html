Molécules

Chaque idée est un atome. Un axiome relie deux idées : c’est une liaison. Relie les atomes qui forment un axiome.

Molécule complète

Clique sur un atome, maintiens, et tire jusqu’à un autre atome. Si les deux idées forment un axiome, la liaison se crée. Les atomes en pointillés bleus viennent des notions précédentes : leurs liaisons sont les axiomes de liaison.
